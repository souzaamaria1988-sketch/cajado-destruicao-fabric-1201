# ⚡ Cajado da Destruição

Mod Fabric 1.20.1 — Cajado mágico com 7 modos de destruição.

## 🎮 Controles
- **Botão direito**: dispara habilidade na direção que está olhando
- **SHIFT + Botão direito**: troca entre os 7 modos
- **Botão esquerdo em mob**: dispara contra o alvo

## Modos: 🔥 Fogo | ⚡ Raio | 🌀 Vazio | 🌊 Tsunami | ☄️ Meteoro | 💀 Praga | 🌪️ Vórtice
